# App Store copy (no AI tells)

Apply to App Store descriptions, What's New, subtitles, promotional text, onboarding, and permission strings.

## Never use

- Em dashes (`—`) or en dashes (`–`). Use a period, comma, colon, parentheses, or a plain hyphen (`-`).
- Range punctuation with en/em dashes. Write `iOS 17-18`, `ages 4+`, `$2.99-$4.99`.
- AI stock phrases: "delve", "leverage", "robust", "seamless", "game-changer", "unlock", "elevate", "transform your", "whether you're", "it's important to note".
- Emoji in App Store metadata unless the brand already uses them.
- Empty superlatives: "best", "ultimate", "revolutionary" without a concrete feature behind them.

## Prefer

- Short sentences. Lead with what the app does.
- Feature bullets that name a real control or screen ("Split view", "Manual save with ⌘S").
- Plain connectors: `and`, `but`, `so`, `or`.
- Contractions when they sound natural in UI copy.

## Examples

```
Bad:  Unlock productivity — seamlessly.
Good: Write markdown. Preview live. Save when you want.

Bad:  Ages 5–8 — fun activities.
Good: Ages 5-8. Short activities.
```

When editing listing files, strip em/en dashes in copy you touch. Keep keywords under Apple's character limits.
